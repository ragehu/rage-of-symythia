# Rage of Symythia

Songs from worlds that never existed.

Cinematic music website featuring the Lucifer Trilogy and standalone music videos.

## Website

https://ragehu.github.io/rage-of-symythia/

## Contents

- Lucifer Ascension — Part I
- Lucifer Dominion — Part II
- Saviour — Part III
- Seven trilogy music videos
- When The Dust Learns Peace and I said Yes! — standalone stories

Static HTML, CSS and JavaScript. No build step required. GitHub Pages serves the main branch root. Video titles, URLs and full descriptions are preserved in catalog.js. YouTube playback requires serving the page over HTTP/HTTPS rather than opening index.html using file://.
